# 📱 Sobre o Projeto

O **StudyFlow** é um aplicativo mobile desenvolvido com o objetivo de auxiliar estudantes na organização de sua rotina de estudos. A aplicação busca oferecer ferramentas que contribuam para o planejamento acadêmico, acompanhamento de progresso e criação de hábitos de estudo mais consistentes.

---

# 🚀 Funcionalidades do Projeto

- Cadastro de matérias
- Registro de sessões de estudo
- Controle de tempo estudado
- Dashboard de acompanhamento
- Progresso semanal
- Sequência de dias estudados
- Organização da rotina acadêmica
